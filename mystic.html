Description

Project context

Mystic Brew was created together with my friends during Game Jam Plus Indonesia 2024. The game takes a cooking inspired concept and transforms it into a potion shop simulation set inside a dungeon themed world.

In this project, I worked as the programmer responsible for the main brewing related systems. My contributions included building the ingredient processing interactions and implementing a recipe structure using Scriptable Objects in Unity so potion creation could be handled in a more scalable way.
