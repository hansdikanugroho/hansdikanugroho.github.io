Description

Project context

CIRT is a team established by PENS to respond to cyber incidents and security related issues. This website project was developed to support that mission by presenting information in a more structured and trustworthy digital form.

In this project, I worked as a UI and UX designer. It was my first major experience in this role, so I spent time studying design principles, interface patterns, and UX laws before translating them into mockups and layout decisions. I completed the UI and UX template work in around two weeks, then continued contributing to the broader project direction as the website moved toward implementation.
