Description

Project context

Mandala: The Minds Journey is a game project developed to participate in an incubation program organized by IGDX. I worked on this project together with my team, Jasuke Studio, to build a psychological horror experience centered on trauma caused by bullying and the lasting impact it can have on someone’s life.

One of the parts I am most proud of is the AI system. I explored adaptive enemy behavior using Behavior Tree based visual scripting, then customized the logic further so the patrol system could behave more dynamically based on mapped point locations. This project gave me room to experiment with more advanced gameplay and AI implementation than I had done before.
